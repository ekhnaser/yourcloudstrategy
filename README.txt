To publish on GitHub Pages:
1. Upload the contents of this folder (not the outer folder) to the root of your GitHub Pages repository.
2. In repository Settings > Pages, deploy from the main branch root (or your preferred Pages configuration).
3. Set your custom domain to yourcloudstrategy.com and configure DNS for GitHub Pages.
4. Purchase buttons currently show a coming-soon message. Replace the [data-buy] links and remove their JavaScript click handler when the Amazon listing URL is ready.
5. Replace/add endorsement text as more approved quotes arrive.

This is a first review version, not a live deployment.
